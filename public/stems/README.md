# Stem files

Drop three stems from the same song here, named by stem id:

    drums.mp3   vocals.mp3   bass.mp3

`.wav`, `.ogg` and `.m4a` also work. All three must be present and the same
length; otherwise BeatDrop falls back to its built-in demo song.

Don't commit copyrighted audio. Add the files to `.gitignore` if needed.
